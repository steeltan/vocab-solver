# vocab-solver

Windows 词汇测试秒答助手：屏幕上常驻一个小面板，**用鼠标点它一下**，就截屏 + OCR 识别屏幕上的英文单词，直接显示中文释义（不猜选项，不需要键盘）。

> 仅供个人背单词/自测使用，请遵守你所在考试或测试的规则。

## 效果

| 情况 | 表现 |
| --- | --- |
| 词库内 | 约 **0.2s** 出意思（目标 < 1s） |
| 词库外 | 先显示「查词中…」，后台联网查词，**硬上限 3s**，结果写到本地缓存，第二次 0ms |
| 查不到 | 提示「没查到释义」，不会瞎给答案 |

实测（1920×1080，识别区域 365×179）：

```
点击 -> 出答案   0.15 ~ 0.20s
OCR 本体         0.14 ~ 0.20s
断网兜底         2.93s
```

## 环境

- Windows 10 / 11
- Python 3.8+
- 显卡支持 DirectML 最好（没有也能跑，走 CPU 会慢一些）

## 安装

```bat
pip install -r requirements.txt
```

## 用法

双击 `启动秒答.bat`（会拉起一个命令行窗口，**别关**）。屏幕上会出现一个小面板：

| 操作 | 作用 |
| --- | --- |
| **左键点面板** | 识别一次，面板里显示单词和中文意思 |
| **按住拖动** | 把面板拖到不挡题目的位置 |
| **右键** | 重新框选题目区域 |
| 关掉黑窗口 / `F8` | 退出 |

第一次用（还没有识别区域）时，面板会显示「点我先框选区域」，点它，然后在屏幕上**拖出题目所在的那一小块**（只框单词那一行最准也最快）。

之后每次答题：点一下面板 → 看意思 → 继续答题。点面板**不会把焦点从考试窗口抢走**。

### 键盘（可选）

不想用鼠标时也可以用键盘：`F9` 识别、`F7` 框选区域、`F8` 退出。

如果按 `F9` 没反应，多半是考试软件以管理员权限运行：关掉窗口，右键 `启动秒答.bat` → **以管理员身份运行**。

## 配置

`vocab_solver.py` 顶部常量：

| 常量 | 作用 | 默认 |
| --- | --- | --- |
| `HOTKEY_TRIGGER` / `HOTKEY_REGION` / `HOTKEY_QUIT` | 键盘等价操作的按键 | f9 / f7 / f8 |
| `ONLINE_BUDGET` | 从点击到出结果的硬上限（秒） | 3.0 |
| `ONLINE_CALL_TIMEOUT` | 单个词典接口超时（秒） | 1.3 |
| `DEBUG` | 保存 `debug_last.png` / `debug_ocr.txt` 便于排查 | False |

## 工作原理

```
点面板 -> 截屏(PIL) -> RapidOCR PP-OCRv4(DirectML) -> 取字号最大的英文 token
       ├─ 词库命中  -> 直接显示释义
       └─ 未命中    -> 先显示「查词中…」，后台请求有道/金山词典，
                      结果写 vocab_solver_cache.json
```

几个关键点：

- 面板跑在独立的 Tk 线程里常驻复用，点击后立刻回「识别中…」，不会卡住界面。
- 面板设了 `WS_EX_NOACTIVATE`，点它不会激活窗口、不会抢走考试窗口的焦点。
- 面板如果正好压在识别区域上，截图前会自动隐藏自己，避免把自己的字识别进去。
- 词库用 `csv` 模块解析，兼容 `comfortable,"舒适的,舒服的"` 这种带逗号的引号字段。
- 选词按 OCR 文本框高度排序，题目单词通常字号最大，不会被指令文字或界面按钮抢走。
- 词库查不到且联网失败时，会用 `difflib` 在本地找近似词兜底（比如 OCR 把 `influence` 读成 `influencc`）。

## 词库

`vocab_bank_大学以上.csv`，格式：

```csv
word,chinese,band,score,max_question_no,times_seen
influence,影响,CET4,11,34,2
```

只有前两列有用，可替换成自己的词表（第一列英文、第二列中文）。

## 常见问题

- **第一次点识别慢一点**：OCR 模型要预热，1~2 秒，之后就快了。
- **面板挡住题目**：按住拖走，位置会自动记住，下次启动还在原处。
- **提示「没识别到英文单词」**：右键重新框一块更贴近单词的区域。
- **改了词库不生效**：重启程序（词库在启动时加载）。
