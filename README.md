# vocab-solver

Windows 词汇测试秒答助手：按 `F9` 截屏 + OCR，识别屏幕上的英文单词，**直接显示中文释义**（不猜选项）。

> 仅供个人背单词/自测使用，请遵守你所在考试或测试的规则。

## 效果

| 情况 | 表现 |
| --- | --- |
| 词库内 | 约 **0.2s** 出意思（目标 < 1s） |
| 词库外 | 先显示「查词中…」，后台联网查词，**硬上限 3s**，结果写到本地缓存，第二次 0ms |
| 查不到 | 提示「没查到释义」，不会瞎给答案 |

实测（1920×1080，识别区域 365×179）：

```
词库命中   influence = 影响          0.18 ~ 0.29s
生词联网   serendipity = 意外发现…   0.20s
断网兜底   两个接口全超时            2.93s
OCR 本体                             0.14 ~ 0.20s
```

## 环境

- Windows 10 / 11
- Python 3.8+
- 显卡支持 DirectML 最好（没有也能跑，走 CPU 会慢一些）

## 安装

```bat
pip install -r requirements.txt
```

## 用法

1. 双击 `启动秒答.bat`（会拉起一个命令行窗口，**别关**）
2. 按 `F7` 框选题目区域 —— 只框「单词那一行」最准也最快
3. 鼠标点回考试页面，按 `F9` 识别
4. 右上角弹出绿色释义；按 `F8` 退出

如果按 `F9` 没反应，多半是考试软件以管理员权限运行：关掉窗口，右键 `启动秒答.bat` → **以管理员身份运行**。

## 配置

`vocab_solver.py` 顶部常量：

| 常量 | 作用 | 默认 |
| --- | --- | --- |
| `HOTKEY_TRIGGER` / `HOTKEY_REGION` / `HOTKEY_QUIT` | 触发 / 框选 / 退出 | f9 / f7 / f8 |
| `ONLINE_BUDGET` | 从按键到出结果的硬上限（秒） | 3.0 |
| `ONLINE_CALL_TIMEOUT` | 单个词典接口超时（秒） | 1.3 |
| `POPUP_SECONDS` | 弹窗停留秒数 | 5.0 |
| `DEBUG` | 保存 `debug_last.png` / `debug_ocr.txt` 便于排查 | False |

## 工作原理

```
截屏(PIL) → RapidOCR PP-OCRv4(DirectML) → 取字号最大的英文 token
        ├─ 词库命中  → 直接显示释义
        └─ 未命中    → 先显示「查词中…」，后台请求有道/金山词典，
                       结果写 vocab_solver_cache.json
```

几个关键点：

- 悬浮窗跑在独立的 Tk 线程里常驻复用，**热键线程不会被弹窗阻塞**（早期版本会阻塞 6 秒，导致连按 F9 全部被吞）。
- 词库用 `csv` 模块解析，兼容 `comfortable,"舒适的,舒服的"` 这种带逗号的引号字段。
- 选词按 OCR 文本框高度排序，题目单词通常字号最大，不会被指令文字或界面按钮抢走。
- 词库查不到且联网失败时，会用 `difflib` 在本地找近似词兜底（比如 OCR 把 `influence` 读成 `influencc`）。

## 词库

`vocab_bank_大学以上.csv`，格式：

```csv
word,chinese,band,score,max_question_no,times_seen
influence,影响,CET4,11,34,2
```

只有前两列有用，可替换成自己的词表（第一列英文、第二列中文）。

## 常见问题

- **第一次按 F9 慢一点**：OCR 模型要预热，1~2 秒，之后就快了。
- **提示「还没框选识别区域」**：区域文件丢了，按 F7 重框一次。
- **弹窗挡住题目**：点一下弹窗就消失，或等它自动关。
- **改了词库不生效**：重启程序（词库在启动时加载）。
